# Documentation website

Open `index.html` directly, or serve the project root and visit `/docs/`. The site uses relative asset links and works under a repository subpath such as `/HanziSpot/`.

No install or build step is needed. All assets are local. The character reference is based on the 156 playable pairs in MainActivity.kt. Search accepts either script, pinyin (with or without tone marks), and English meanings. The practice grid is an illustrative browser example.

To publish using GitHub Pages, open repository Settings → Pages, select Deploy from a branch, choose the intended branch and `/docs`, then save. Repository visibility and account plan may affect Pages availability. A push alone does not enable Pages.

When updating app build versions or character pairs, update the corresponding documentation. Current build files are intentionally preserved.

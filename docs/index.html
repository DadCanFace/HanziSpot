01 / GET STARTED

From source to your phone.

Download Hanzi Spot v1.0 APK for Android 6.0 or newer. Open the downloaded APK on your Android device to install it.

Expert mode is available in the v1.1 source and will be included in the next APK release.

You need Android Studio, JDK 17 or 21, and Android SDK Platform 35. The app runs on Android 6.0 (API 23) and newer.

  1. Open the project

    Choose Open in Android Studio and select HanziSpot, the folder containing settings.gradle.kts.

  2. Check the Gradle JDK

    Open Settings → Build, Execution, Deployment → Build Tools → Gradle. Select JDK 17 or 21 for the documented Gradle 8.11.1 baseline.

  3. Sync, then run

    Install SDK Platform 35 when prompted. Let Gradle sync, choose an emulator or connected phone, and click Run. The first build needs internet for dependencies.

Build configuration note

The Desktop copy currently specifies Gradle 9.0, AGP 8.9.1, and Kotlin 2.2.21. The original project used Gradle 8.11.1. This documentation change preserves the current files. If sync fails, restore the original wrapper version and use JDK 17 or 21, or upgrade the build stack together.

Build from a terminal

Run from the project root with your Android SDK configured.

Windows · PowerShell
.\gradlew.bat :app:assembleDebug
macOS / Linux
sh gradlew :app:assembleDebug

Find the debug APK at app/build/outputs/apk/debug/app-debug.apk.

02 / THE GAME

Find the one that changes.

Each grid repeats one character, with a single tile written in the other script. Odd-numbered rounds ask for Traditional; even-numbered rounds ask for Simplified.

Try a practice grid

Find the Traditional character among these Simplified characters. This is a website example; it does not affect your Android scores.

Look closely at the strokes.

Choose your grid size
DifficultyGridTiles
Easy3 × 39
Medium4 × 416
Hard5 × 525
Expert5 × 525
  • Correct answer: earn 10 points and see the pair, pinyin, and meaning.
  • Hint: highlights the correct tile in gold; that round earns 5 points.
  • Wrong answer: lose one heart. A previously wrong tile becomes disabled.
  • Finish: complete all rounds or lose all 3 hearts. Easy, Medium, and Hard have 10 rounds. Expert shuffles all 156 pairs without repeats and restores one heart every 10 correct answers, including hinted answers, up to three hearts. There is no time limit.
  • Records: best completed-game scores are saved separately for each difficulty.

Tap the character pair’s Listen button after a correct answer to choose Mandarin or Cantonese. Playback uses an installed offline voice in Android’s text-to-speech settings. The engine may choose a different reading for characters with multiple pronunciations.

Leaving through “Back to menu” asks for confirmation and discards the current game.

04 / UNDER THE HOOD

Small, native, easy to explore.

The app uses Kotlin and Android platform Views. One Activity creates the menu, game board, and results screens programmatically.

Source map
FileResponsibility
MainActivity.ktDataset, game state, scoring, grids, navigation, and screen rendering
res/values/styles.xmlApp theme and system bar colors
AndroidManifest.xmlApplication and launcher Activity configuration
app/build.gradle.ktsSDK levels, application identity, and JVM target

The Activity source lives at app/src/main/java/com/hanzispot/game/MainActivity.kt.

Game flow

Choose difficulty→Spot a character→Learn the pair→Results

start() shuffles the vocabulary and uses 10 pairs for standard difficulties or all 156 for Expert. newBoard() randomizes the target tile. board() handles answers; results() saves the best score.

Add a character pair

Add a PairWord entry to the list in MainActivity.kt. Use single characters with different forms and a representative reading and meaning.

PairWord("學", "学", "xué", "to learn")

Regenerate or update the reference table here when changing the dataset.

State and persistence

onSaveInstanceState() saves the round, order, score, hearts, target, hint, and mistakes for Activity recreation. Best scores use local SharedPreferences named records, with keys best3, best4, and best5, and bestExpert. A new cold launch starts at the menu.

Manual checks

  • Play every difficulty and verify exactly one different tile per grid.
  • Check alternating scripts, 10-point answers, and 5-point hinted answers.
  • Lose three hearts; complete ten rounds; replay and change difficulty.
  • Rotate before and after answering, then check state restoration.
  • Reopen the app and check high scores; test small screens and landscape scrolling.
Verification record

The original Kotlin source compiled against installed Android API 37 stubs, and XML and dataset checks passed. The original full build failed under Java 25. No device or emulator run was recorded. These are historical checks, not verification of the current Gradle 9.0 configuration.

05 / HELP

Get unstuck.

Gradle sync fails or reports Java 25

Check your Gradle JDK, not only the IDE runtime. For the original Gradle 8.11.1 configuration, choose JDK 17 or 21. The current Desktop wrapper is Gradle 9.0; see the configuration note above before changing versions.

SDK Platform 35 is missing

Open Android Studio’s SDK Manager and install Android SDK Platform 35. Ensure local.properties points to your local SDK, or set ANDROID_HOME. Do not commit machine-specific SDK paths.

No device is available

Create an Android Virtual Device in Device Manager, or connect a phone with USB debugging enabled and approve its debugging prompt. Use API 23 or newer.

The website does not load at /docs

This folder is a static site. Serve the project root to visit /docs/, or open docs/index.html directly. For GitHub Pages, select a branch and the /docs folder as the publishing source in the repository’s Pages settings. Pushing files alone does not enable Pages.

06 / ON YOUR DEVICE

Play offline. Keep scores local.

The current app manifest requests no network permission. Gameplay needs no account, advertising service, or remote backend. Best scores stay in the app’s local preferences.

Android system backup may include application data because backup is enabled in the manifest. Clearing app data resets local preferences; system restore behavior depends on the device’s backup settings.

This documentation uses no external fonts, trackers, or JavaScript dependencies. The practice grid is temporary and does not save results.
